# AI-Assisted Construction Inspection

Monorepo for Python and TypeScript applications, services, and shared packages.

## Repository Layout

| Folder | Purpose |
|--------|---------|
| `apps/` | User-facing applications (web, CLI, desktop). |
| `services/` | Backend services and APIs. |
| `packages/` | Shared libraries and utilities used across apps and services. |
| `infra/` | Infrastructure as code, deployment configs, and environment definitions. |
| `tests/` | Cross-cutting integration and end-to-end tests. |
| `data/raw/` | Unprocessed source datasets and inputs. |
| `data/processed/` | Cleaned, transformed, and model-ready datasets. |
| `data/reports/` | Generated reports, exports, and analysis outputs. |
| `docs/` | Project documentation, guides, and architecture notes. |
